🎴 Слайд 2. Что такое «Игра в жизнь»
Кто говорит: karenadw.

text
Игра в жизнь (Game of Life) — клеточный автомат.

Правила:
  1. Живая клетка с 2 или 3 живыми соседями  →  выживает
  2. Живая клетка с <2 или >3 соседями       →  умирает
  3. Мёртвая клетка ровно с 3 соседями       →  рождается

Поле: 80 столбцов × 25 строк = 2000 клеток
Замкнуто в тор: края соединены (левый с правым, верхний с нижним)
Что сказать: «Игра — это клеточный автомат. Правил всего три. У каждой клетки 8 соседей. Поле замкнуто в тор — то есть если глайдер уходит за правый край, он появляется слева».

🎴 Слайд 5. Как работает заворачивание на тор
Кто говорит: karenadw. Это самый важный слайд для защиты.

c
nr = (row + dr + HEIGHT) % HEIGHT;
nc = (col + dc + WIDTH)  % WIDTH;
text
Пример: клетка (0, 0) в левом верхнем углу.
Сосед сверху-слева: dr = -1, dc = -1.

  row + dr = 0 - 1 = -1     ← недопустимый индекс!
  
  (0 - 1 + 25) % 25 = 24    ← корректно, идём в строку 24
  (0 - 1 + 80) % 80 = 79    ← корректно, идём в столбец 79

Сосед сверху-слева от (0,0) — это (24, 79), нижний правый угол.
Логично: тор соединяет края.
Что сказать: «Это ключевой момент. Мы используем остаток от деления для заворачивания. Важно: в C -1 % 25 == -1, а нам нужно 24. Поэтому мы прибавляем размер поля перед взятием остатка. Формула (координата + смещение + размер) % размер гарантирует индекс в диапазоне [0, размер-1]».

Готовься к вопросу пира: «Почему + HEIGHT?» — «Потому что в C остаток отрицательного числа отрицателен, а прибавив размер, мы получаем неотрицательный аргумент».

🎴 Слайд 6. Функция count_neighbors
Кто говорит: karenadw.

c
int count_neighbors(const Game *game, int row, int col)
{
    int count = 0;
    int dr = -1;
    // ...
    while (dr <= 1) {
        dc = -1;
        while (dc <= 1) {
            if (dr != 0 || dc != 0) {          // пропускаем саму клетку
                nr = (row + dr + HEIGHT) % HEIGHT;
                nc = (col + dc + WIDTH) % WIDTH;
                count += game->field[nr][nc];
            }
            dc++;
        }
        dr++;
    }
    return (count);
}
Что сказать: «Мы перебираем 9 позиций вокруг клетки через смещения dr и dc от -1 до +1. Позиция (0,0) — это сама клетка, мы её пропускаем. Для каждой позиции вычисляем координаты с заворачиванием и прибавляем значение. Так как живые клетки хранятся как 1, а мёртвые как 0, сумма даёт число живых соседей».

🎴 Слайд 7. Почему нужен второй массив
Кто говорит: karenadw.

text
Проблема:
  Если писать новое поколение прямо в field,
  изменённые клетки повлияют на ещё не обработанные.

Решение:
  1. Считаем все новые значения в отдельный массив next
  2. Копируем next → field одним махом

    int next[HEIGHT][WIDTH];
    ...
    game->field[row][col] = next[row][col];
Что сказать: «Правила Конвея применяются одновременно ко всем клеткам. Если бы мы писали сразу в field, изменённая клетка повлияла бы на своих соседей, которые ещё не обработаны. Поэтому мы сначала считаем всё в массив next, потом копируем обратно».

Готовься к вопросу: «А почему не memcpy?» — «В Школе 21 мы предпочитаем явные циклы, плюс memcpy требует string.h. Оба варианта корректны».

🎴 Слайд 8. Интерфейс: ncurses
Кто говорит: ambrosto.

text
Библиотека ncurses:
  • прямая работа с терминалом (курсор, цвета, символы)
  • обработка клавиш без ожидания Enter (cbreak, noecho)
  • символы псевдографики (ACS_*)

Что мы используем:
  initscr / endwin       — инициализация и завершение
  mvaddch / mvprintw     — рисование в координатах
  attron / attroff       — цвета и жирность
  timeout / getch        — пауза и чтение клавиш
  has_colors             — проверка поддержки цветов
Что сказать: «Интерфейс мы сделали на ncurses. Она умеет работать с терминалом напрямую: ставить курсор в любую точку, менять цвета, рисовать рамки. На Windows и Linux заголовок лежит в разных местах, поэтому мы используем условный include через #if defined(_WIN32)».

Готовься к вопросу: «Что такое timeout?» — «Это функция ncurses, задаёт максимальное время ожидания клавиши в getch. Если клавиша не нажата за это время — getch возвращает ERR, и цикл продолжается».
